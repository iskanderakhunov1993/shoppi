# Shoppi

## Продукт
- Что это: витрины блогеров — блогер собирает в одну страницу товары, которые сам советует, из любых магазинов (маркетплейсы, сайты брендов, любые магазины); подписчики находят, сохраняют и покупают по ссылке.
- Для кого: покупатели из Instagram/Telegram (массовый рынок, чек 400–1500 ₽) и блогеры 1–50k подписчиков.
- Главная ценность: «покупайте то, что советуют люди, а не реклама». Бесплатно, без наценки, реклама помечена, цифры честные (боты отделены).
- Роли: покупатель, блогер (в коде — creator), бренд (на паузе, BRANDS_ENABLED=false).

## Стек и окружение
- Next.js 16 (App Router, читать node_modules/next/dist/docs перед кодом), TypeScript, Tailwind v4, Postgres (Supabase) через `postgres`.
- Продакшен: https://myshop-murex-nine.vercel.app (Vercel, автодеплой с master).
- Превью: Vercel preview на каждую ветку.
- База: схемы public (прод) / dev (next dev) / test (vitest). Прод трогает только владелец. Миграции — scripts/migrations/*.sql; применять к dev/test самому, SQL для public отдавать владельцу и после деплоя проверять прод.
- Команды: `npm run dev`, `npm run build`, `npm test`, `npm run lint`, `npx tsc --noEmit -p .`. Dev-сервер для браузера: .claude/launch.json → myshop-dev.
- Демо-вход в dev: /api/dev/quick-login {role: shopper|creator|brand} (только не в продакшене).

## Правила текста и дизайна
- Язык интерфейса — русский, на «вы». Термины: «блогер» (не «креатор»), «рекомендации» (не «находки»).
- Нельзя писать, что товары только с WB/Ozon — магазин любой.
- Тексты прогонять через humanizer: без тире-связок, «не X, а Y», штампов.
- Лендинг: стиль «люди, а не реклама» (.lv4: лавандовый серый + фиолетовый, Unbounded/Onest). Остальной продукт: тёмный журнальный стиль (Playfair + Inter). Витрина блогера — в духе ShopMy.
- Макеты и варианты — design-explorations/.
