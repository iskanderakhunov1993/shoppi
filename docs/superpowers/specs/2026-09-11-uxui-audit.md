# UX/UI-аудит Shoppi (ветка `uxui`)

Статус: аудит + предложены визуальные направления, код ещё не менялся.

## Что оценивалось

Текущий продукт: лендинг (ролевые страницы, каталоги, поиск), три кабинета
(куратор/шоппер/бренд), публичная витрина куратора, медиакит. Дизайн-система:
Fraunces (дисплей) + Inter (текст), чёрно-белая палитра с `--ink/--paper`,
hairline-границы, тёмная тема по системным настройкам.

## Usability

| Находка | Серьёзность | Комментарий |
|---|---|---|
| Форма товара куратора — 5 полей вертикальным списком, все визуально одного веса | 🟡 Средне | Обязательные (название, ссылка, категория) и необязательные (фото, цена, промокод) поля неотличимы друг от друга — уже отмечено в продуктовом анализе ранее в этой сессии, не переделано в коде |
| Кабинет бренда — форма CPA-ссылки и форма артикулов визуально идентичны (одинаковый инпут, нет группировки) | 🟡 Средне | Технически два разных механизма монетизации выглядят как одна форма — новому пользователю неочевидно, что это два разных шага |
| Промокод на витрине — обычный текстовый чип без разницы с ценой | 🟢 Мелкое | Промокод — это призыв к действию ("возьми скидку"), а выглядит как метаданные |
| Onboarding-бейдж куратора виден только по клику | 🟢 Мелкое | Уже отмечено ранее, не критично |

## Визуальная иерархия и консистентность

- Чёрно-белая система читаема, но **не различает роли** — куратор, бренд и
  шоппер видят визуально один и тот же кабинет (тот же шрифт, тот же серый
  hairline), различие только в тексте заголовка. Для мультиролевого продукта
  это создаёт ощущение "один шаблон с разными полями", а не осознанно
  спроектированных трёх кабинетов.
- Акцентного цвета нет вообще — весь UI монохромный. Это стилистически
  цельно, но не даёт инструмента для выделения денег/статуса/CTA без
  использования одного и того же чёрного веса на всё.
- Цифры (клики, цена, счётчики) набраны тем же шрифтом, что и текст — нет
  моноширинного/табличного начертания для данных, хотя продукт по сути
  аналитический (медиакит, счётчики кликов, суммы).

## Доступность

- Контраст текста на фото (hero) — приемлемый, использует чёрный scrim.
- Фокус на инпутах/кнопках — не проверялся визуально в этом аудите,
  зафиксировать в следующем проходе.

## Вывод

Текущая система "издательский минимализм" (Fraunces + hairlines) — рабочая
основа, но однородная для всех трёх ролей и не использует цвет и типографику
данных как инструмент. Ниже — три визуальных направления развития, каждое
сохраняет честный тон бренда (никаких фейковых чисел, никакого маркетингового
глянца), но по-разному решает роль цвета, иерархии данных и характера کураторской
витрины. Макеты сделаны на реальном контенте продукта (Белла/Максим/Соня,
категории, тексты) для честного сравнения — не Lorem Ipsum.

См. три HTML-макета в артефактах чата данной сессии для визуального сравнения.
